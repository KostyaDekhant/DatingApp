На сервере развернута СУБД PostgreSQL16
Наименование службы postgresql@16-main 
systemctl status postgresql@16-main - статус службы
systemctl start postgresql@16-main - запуск службы
systemctl stop postgresql@16-main - остановка службы
systemctl restart postgresql@16-main - перезапуск службы

Само серверное приложение находится в каталоге /opt/datingapp
!!!Файл службы тут не актуален!!! - Актуальный лежит в /usr/lib/systemd/system/datingapp.service
Для его просмотра использовать например cat <путь до файла>. Для правки можно использовать nano или vi (:qa для выхода без сохранения;) )
Команды аналогичный как и для postgres - имя службы datingapp 
ЛОГИ: дополнительно сделал вывод логов. В том же каталоге в /opt/datingapp/log

ОБНОВЛЕНИЕ: для обновления достаточно подкинуть jar файл с тем же названием и перезапустить службу
КОНФИГУРАЦИЯ: application.properties лежит рядом с jar, параметры подтягиваются из него, так что их можно менять.
